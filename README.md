# MedTekser

Шымкент пен Түркістан облысындағы компанияларға арналған корпоративтік медтексеру өтінімдерінің сайты. Жоба статикалық RU/KK сайтынан, HR кабинетінен, оператор панелінен және стандартты Python кітапханаларына негізделген SQLite API-дан тұрады.

## Қазіргі жарияланған күйі

- GitHub Pages тек `static/` бумасын жариялайды. Python API бұл URL-де жұмыс істемейді.
- `static/api-config.js` ішінде API және құпиялық хабарламасы URL-дары бос. Сондықтан жария сайт өтінімді серверге жібермейді және «қабылданды» деп көрсетпейді; WhatsApp байланысын ұсынады.
- Медициналық/мемлекеттік тізілім тексергіші қосылмаған. Лендингте ЖСН енгізбеңіз.
- Серіктес клиника, лицензия, тариф, бос уақыт немесе заңдық сәйкестік туралы расталмаған мәліметтер жарияланбайды.

## Жергілікті іске қосу

Python 3.9+ қажет. Қосымша кітапхана орнатылмайды:

```bash
python3 server.py
```

- Сайт: http://localhost:8000
- HR кабинеті: http://localhost:8000/cabinet
- Оператор панелі: http://localhost:8000/admin

Әдепкі `APP_ENV=development` серверді тек `127.0.0.1` адресіне байлайды. Дерекқор бастапқыда бос болады; демо өтінім, қызметкер, клиника немесе кіру коды автоматты түрде жасалмайды. `api-config.js` бос қалса, браузерлік preview жұмыс істейді; баннер деректердің тек осы браузерде сақталатынын және жергілікті кіру сервермен расталмайтынын ескертеді. Ондағы сәтті хабарлама операторға жіберілгенін білдірмейді. Нақты жеке немесе медициналық деректерді енгізбеңіз. Python API-ды конфигурациялау үшін `static/api-config.js` ішіне `http://localhost:8000` жазыңыз, серверді `ADMIN_PASSWORD` ортасымен іске қосыңыз және өтінім қабылдау үшін HTTPS `PRIVACY_NOTICE_URL` беріңіз. Құпиясөз орнатылмаса, API серверлік әкімші кіруін өшіреді. Production режимінде кемінде 16 таңбалы `ADMIN_PASSWORD` міндетті.

## API-ды бөлек серверге орналастыру

GitHub Pages backend іске қоспайды. Нақты өтінім қабылдау үшін Python серверіне HTTPS мекенжайы және `/data` үшін тұрақты диск қажет.

1. API домені дайын болғанда `static/api-config.js` файлына қойыңыз:

```js
window.MEDTEKSER_API_BASE_URL = "https://api.example.kz";
```

API хостына `PRIVACY_NOTICE_URL` HTTPS айнымалысын беріңіз. API осы мекенжайды форма мен кабинетке жариялайды. Production-та құжат URL-ы болмаса сервер іске қосылмайды; кез келген ортада URL болмаса, өтінім мен қызметкер тізімін сақтау endpoint-тері `503` қайтарады. API мекенжайы бос болса жария сайт WhatsApp fallback режимінде қалады.

2. Алдымен құпиясөз бен бекітілген HTTPS құпиялық құжатының адресін `MEDTEKSER_ADMIN_PASSWORD` және `MEDTEKSER_PRIVACY_NOTICE_URL` орта айнымалыларына қауіпсіз сақтаңыз. Docker контейнерін тұрақты `/data` дискімен іске қосыңыз; айнымалылар берілмесе команда тоқтайды:

```bash
docker build -t medtekser .
docker run -d --name medtekser \
  -p 8000:8000 \
  -v medtekser-data:/data \
  -e APP_ENV=production \
  -e ADMIN_PASSWORD="${MEDTEKSER_ADMIN_PASSWORD:?Set a unique 16+ character secret}" \
  -e ALLOWED_ORIGINS="https://dansho09.github.io" \
  -e PRIVACY_NOTICE_URL="${MEDTEKSER_PRIVACY_NOTICE_URL:?Set an approved public HTTPS privacy notice URL}" \
  medtekser
```

Production режимі `ADMIN_PASSWORD` кемінде 16 таңба болмаса, серверді іске қоспайды. `ALLOWED_ORIGINS` нақты сайт Origin-імен шектеледі; бірнеше Origin үтірмен бөлінеді. Ашық өтінімдер бір IP-ден 10 минутта 5 ретпен, ал әкімші/компания кіруі әрқайсысы 15 минутта 10 әрекетпен шектеледі. IP мекенжайлары тек уақытша жадыда қолданылады және SQLite-ке жазылмайды. Әкімші сессиясы 12 сағат, компания сессиясы 14 күн жарамды.

Дерекқорды жоғалтпау үшін `/data` томын сақтаңыз. Серверді тек HTTPS reverse proxy арқылы жариялаңыз. API орналастырушысының проксиі бастапқы клиент IP-ін өзгертсе, rate limit-тің хостинг ортасында қалай істейтінін тексеріңіз.

## GitHub Pages

`.github/workflows/pages.yml` тек `static/` бумасын жариялайды. API бөлек хостта іске қосылады. Осы реподағы кодты өзгерту автоматты түрде жарияламады; сайтты жаңарту үшін репозиторийдің `main` тармағына жариялау керек.

Нағыз өтінім қабылдауды қосар алдында API доменін, тұрақты дерек сақтау орнын және құпиялық хабарламасын бекітіңіз. Сайтта клиника, баға немесе қызмет деректерін нақты жарияламас бұрын оларды да растаңыз. Жоба мемлекеттік немесе медициналық тізіліммен интеграция жасамайды және медициналық не заңдық қорытынды бермейді.
