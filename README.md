# MedTekser — корпоративтік медициналық тексеру платформасы

Шымкенттегі компаниялар қызметкерлерінің мерзімді, жұмысқа кірер алдындағы және ауысым алдындағы медициналық тексерулерін бір терезеден ұйымдастыратын веб-платформа.

## 🚀 Жылдам іске қосу (қосымша кітапхана қажет емес)

Тек Python 3.9+ жеткілікті:

```bash
cd /Users/daniyar/.gemini/antigravity/scratch/medtekser
python3 server.py
```

Ашылатын беттер:
- **Лендинг және калькулятор:** http://localhost:8000
- **Компания кабинеті:** http://localhost:8000/cabinet (демо кіру: Өтінім № `1`, Код `DEMO12`)
- **Админ панель:** http://localhost:8000/admin (әдепкі құпиясөз: `admin123`)

## ✨ Негізгі мүмкіндіктер

1. **Заманауи лендинг және онлайн-калькулятор**
   - Қызмет түрлері бойынша интерактивті баға есептегіш
   - Зиянды фактор үстемесі мен сервис комиссиясын автоматты есептеу
   - Өтінім жіберген сәтте жеке кабинет коды мен сілтемесін генерациялау
   - Спам-боттардан қорғаныс (honeypot) және телефон/БСН валидациясы

2. **Компанияның жеке кабинеті (`/cabinet`)**
   - Өтінім нөмірі мен 6 таңбалы код арқылы қауіпсіз кіру (сессиялар SQLite-та 14 күн сақталады)
   - Қызметкерлер тізімін **CSV файл ретінде сүйреп тастау (drag-and-drop)** немесе **Excel-ден тікелей көшіріп қою**
   - Нақты уақыттағы тексеру прогресі (Жарамды, Жарамсыз, Жоспарланды, Келмеді, Күтуде)
   - Іздеу, мәртебе бойынша сүзгі және ресми есепті басып шығару (`window.print()`)

3. **Оператор / Админ панелі (`/admin`)**
   - KPI мен аналитика: барлық өтінім, тексерілген қызметкерлер, жалпы айналым және таза сервис комиссиясы
   - Өтінімге серіктес клиника мен нақты тексеру күнін бекіту
   - Клиентке кабинет сілтемесін 1 батырмамен WhatsApp-қа жіберу немесе көшіру
   - Қызметкерлер тізімін **Excel-ге (UTF-8 BOM CSV)** жүктеп алу
   - Барлық қызметкерге бірден мәртебе беру және әр қызметкерге дәрігер қорытындысын жазу
   - Серіктес клиникалар тізімін басқару (қосу / өшіру)

4. **Telegram хабарламалар**
   - `TELEGRAM_BOT_TOKEN` және `TELEGRAM_CHAT_ID` орнатылса, әр жаңа өтінім түскенде оператордың Telegram-ына лезде хабарлама келеді.

## 🌐 Интернетке (продакшнға) шығару

### Docker арқылы іске қосу
```bash
docker build -t medtekser .
docker run -d --name medtekser \
  -p 8000:8000 \
  -v $(pwd)/data:/data \
  -e ADMIN_PASSWORD="СіздіңКүштіҚұпиясөзіңіз" \
  -e CONTACT_PHONE="+77001234567" \
  -e PUBLIC_URL="https://medtekser.kz" \
  medtekser
```

### Render / Railway / Fly.io немесе VPS-ке қою
- Репозиторий ішінде дайын `Dockerfile` бар.
- Дерекқор өшпеуі үшін `/data` папкасына тұрақты диск (Persistent Volume) жалғаңыз.
- HTTPS үшін VPS қолдансаңыз, алдына Caddy қойсаңыз жеткілікті:
  ```
  medtekser.kz {
      reverse_proxy localhost:8000
  }
  ```
